# Candidate privacy policy

This local candidate is an allowlisted publication package. The default is to
exclude material rather than attempt to redact a copied private tree.

The candidate contains no raw runtime traces, raw model or provider responses,
credentials, authentication material, user data, machine inventory, private
operational records, game saves, native captures, proprietary game assets, or
private Git history.

Derived evidence must identify its origin, derivation method, supported claim,
privacy classification, and qualification level. A derived summary is not raw
experimental evidence.

The verifier audits exact filenames, path classes, content markers, absolute
local paths, secret-like assignments, authentication material, machine
identifiers, and unsupported executable artifacts. False positives must be
reviewed explicitly; checks must not be weakened merely to obtain a pass.

The target microsite is static and contains no authentication, database,
tracking, analytics, email, runtime model call, or external API dependency.
